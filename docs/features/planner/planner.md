## 개발 환경

언어 : TypeScript
선정 이유 : pdf-lib 와 결제 컴포넌트 등을 타입 오류 없이 일관되게 사용할 수 있으며 AI에게 작업을 맏길 경우 타입 오류로 절반을 거를 수 있기 때문

프론트 엔드 프레임 워크 : Next.js (App Router)
선정 이유 : E2E 테스트가 한 프로세스만 띄우면 되고 파일 경로를 읽기 쉬우며 기능마다 md를 읽기 쉬워서

백엔드 프레임 워크: Nest.js
선정 이유 : Js로만 백엔드를 구성할 경우 트렌잭션 등을 직접 만드는 문제가 있어 안정적인 백엔드 필요

데이터 베이스 : PostgreSql

프론트 프레임워크 :React
선정 이유 : Next.js 안에 포함된 기능이라 같이 사용하는게 더 효율적이고 상태관리가 편해서

CSS는 일반 CSS 버전

버전 형상관리 : Git

인프라 : Docker

배포: Ci/CD Github Actions

테스트 : Vitest , K6, 테스트 컨테이너로 실제 프로덕트 환경이 필요한 경우 사용 이 외에는 내부 데이터베이스 (H2) 로 한다.

회원 가입

- 주소 받기 - 우체국 API 를 활용하여 정확한 주소 받기
- 앱인 경우 GPS로 받거나 웹은 다른 묘수 있으면 도입
- 로컬 회원가입으로 전재로 하고 우리 측에서 제공한 PDF 동의서를 지급함
- 사용자가 싸인까지 하고 동의하면 이 싸인을 PNG로 저장하여 동의서에 덛씌움
- 이메일 인증 난수 생성

### 회원 수정

- 비밀번호 수정은 막히게 한다

### 일거리 등록

- 일거리 등록시 각각의 카테고리를 제공함
- 카테고리 별로 일거리 등록시 꼼꼼히 써야하는 유의 사항을 플레이스 홀더로 보여주도록 한다.
- 기본적으로는 회원가입 등록 주소를 사용하되 다른 주소를 알바 장소로 추가할 수 있도록 함.
- 공고 버전, 등록 시간, 수정 시간, 금액 은 꼭 들어가야함
- 모

### 일거리 수정

- 일거리 요청자가 있으면 요청한 시간대의 공고를 기록 한다.
- 사용자가 공고 수정할 때 마다 version 의 number를 +1 씩 하여서 사용자가 신청한 공고의 버전과 비교하여 다르면 다시 확인하라고 한다.
- 주소, 금액, 시간, 필수 일거리 내용, 등 필수 고지 사항이 수정된 경우만 버전이 업 될 수 있도록 만든다.
  [이 부분은 아직 정의가 미흡하여 AI인터뷰 혹은 클로드에게 자문 구함]
- 확인 하고 계약이 체결될 경우 양자는 2시간 안에만 취소가 가능하다.
- 노쇼 / 당일 취소 / 시간이외의 불가피 취소를 5회 이상한 사람은 5일간 공고 등록 및 알바 신청 불가

### 일거리 삭제

- 서로 컨텍이 된게 없으면 삭제 가능
- 경합확정이되면 삭제 가능
- 3시간전에 모집인원 미달일 경우 공고를 연장할지 / 삭제할지 정하도록 알림을 보내고 아니면 개속 유지할지 정하도록 한다.
- 만약 급구 공고나 6명 중 3명이 경합이 될 경우 취소를 하면 경고 스택이 쌓여 이용에 재한을 둔다

### 거래 후기 평점

- 기능이 너무 많아지고 신고랑 블랙리스트 해야해서 그냥 별점 정도만 주는걸로 합의
- 회원가입자의 유니크기 id를 참조하여 평점의 평균을 계산하여 보여주도록 한다.

### 로그인 기능

- JWT 방식으로 진행
- 로그아웃이 될 경우 뒤로가기 및 앞으로가기 등으로 로그인 전용 페이지는 못보게 해야함

### 결재 및 지급

- 포인트 방식으로 진행하며 공고를 올리는 사람은 사이트에서 포인트를 금액 만큼 결제함
- 공고 생성시 해당 공고의 인원수 * 보상금 만큼 포인트가 차감됨
- 업무가 완료되었다고 확인이 되면 채결한 사람들에게 포인트가 지급된다.
- 포인트가 지급되면 최소 5000원 이상 & 10원 단위로 일주일 후에 정산된다고 알림
