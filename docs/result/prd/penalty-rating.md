## 1. 개요

### 목적

약속을 어기는 사람에게 비용을 물리고(제재), 신뢰할 만한 사람을 드러낸다(평점). **이 도메인이 서비스의 신뢰를 만든다.**

### 왜 한 PRD로 묶는가

둘 다 "거래 후 남는 사람에 대한 평가"이고, 둘 다 `Application` 완료·취소 이벤트에서 파생되며, 둘 다 회원 상세 화면에서 함께 보인다.

### 범위

- `Penalty` 건별 기록 (노쇼·지각취소·당일취소·구인자취소)
- 180일 롤링 5건 → 5일 제재 판정
- 제재 중 행위 차단
- 블랙리스트(= 제재 목록) 관리자 화면 및 조기 해제
- 별점 1~5 양방향 입력, 역할별 평균 집계

---

## 2. 사용자 스토리

### 제재

- **구인자로서** 자주 펑크 내는 사람이 걸러지기를 원한다. 당일에 사람이 안 오면 일이 멈춘다.
- **구직자로서** 공고를 마음대로 취소하는 구인자도 똑같이 제재받기를 원한다. 일방적이면 불공정하다.
- **제재당한 회원으로서** 왜, 언제, 무엇 때문에 제재됐는지 알고 싶다.
- **오래된 회원으로서** 2년 전 실수 하나가 영원히 따라다니지 않기를 원한다.
- **관리자로서** 억울한 제재를 사유를 남기고 조기 해제할 수 있어야 한다.
- **관리자로서** 누가 왜 제재를 풀었는지 추적할 수 있어야 한다.

### 평점

- **구인자로서** 지원자의 평점을 보고 수락 여부를 판단하고 싶다.
- **구직자로서** 구인자의 평점을 보고 지원 여부를 판단하고 싶다. **구인자로서의 평판과 구직자로서의 평판은 별개**여야 한다.
- **신규 회원으로서** 별 하나 받았다고 평점 1.0으로 낙인찍히지 않기를 원한다.
- **거래 당사자로서** 실제로 거래한 건에 대해서만, 한 번만 평가할 수 있기를 원한다.

## 4. Out of Scope

| 항목                                   | 이유                                                   |
| -------------------------------------- | ------------------------------------------------------ |
| 텍스트 후기 / 리뷰 본문                | planner.md에서 명시적으로 제외 — "그냥 별점 정도만"    |
| 신고 기능                              | 위와 동일                                              |
| 관리자 수동 영구 차단 목록             | 블랙리스트 = 자동 제재 목록으로 확정 (spec-fixed §5.1) |
| 가중 점수제 (노쇼 3점·당일취소 2점 등) | 5건 단순 카운트                                        |
| 평점에 따른 노출 우선순위 / 랭킹       | 표시만                                                 |
| 평점 이의제기 / 삭제 요청              | 없음                                                   |
| 배지·등급·인증 마크                    | 없음                                                   |
| 제재 단계별 차등 (1차 경고 → 2차 정지) | 5건 → 5일 단일 규칙                                    |
| 제재 이력 사용자 공개                  | 본인과 관리자만                                        |
| 자동 제재 이메일 이의신청 폼           | 관리자 수동 해제로 갈음                                |

## 5. 용어 정의

| 용어       | 코드 식별자  | 정의                                                                          |
| ---------- | ------------ | ----------------------------------------------------------------------------- |
| 경고       | `Penalty`    | 노쇼·당일취소 등으로 쌓이는 제재 기록 1건                                     |
| 제재       | `Suspension` | 경고 누적으로 발생한 이용 제한 (5일)                                          |
| 블랙리스트 | _(개념)_     | **자동 제재된 회원의 목록**. 별도 테이블 아니며 `Suspension` 조회의 다른 이름 |
| 제재 해제  | `releasedAt` | 관리자가 만료 전에 조기 종료한 것                                             |
| 평점       | `Rating`     | 거래 후 남기는 별점 (1~5)                                                     |

### 확정 규칙

- **최근 180일 롤링 윈도우 내 5건 이상 → 5일 제재**
- 제재 중 차단: 공고 등록, 알바 신청. **계약 이행·환전·조회는 계속 가능**
- 평점 표본 3건 미만 → 평균 대신 **"신규"** 표시
- 역할별 분리 집계: `ratingAsPoster` / `ratingAsWorker`
- 제재 해제 시에도 원본 `Penalty`는 유지
